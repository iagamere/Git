تسجيل الدخول

سجّل دخولك بحساب GitHub مباشرة، بدون توكن ولا كلمات مرور. يبقى حسابك مرتبطاً ولا تحتاج الدخول كل مرة.

افتح GitHub وأدخل هذا الرمز ثم اضغط Authorize:

نسخ الرمز وفتح GitHub

إعداد لمرة واحدة: أنشئ تطبيق OAuth خاصاً بك لربط الدخول.

  1. افتح github.com/settings/developers ← OAuth Apps ← New OAuth App
  2. الاسم أي اسم، وفي Homepage و Callback اكتب https://github.com
  3. فعّل خيار Enable Device Flow ثم Register
  4. انسخ Client ID والصقه هنا
